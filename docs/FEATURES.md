# Features List

本文件記錄「控糖網站」的功能清單、行為描述與目前開發狀態。

## 1. 核心功能：進食順序評分 (Meal Order Scoring)

### 1.1 記錄進食序列
- **行為描述**: 使用者可以依序點選或拖曳「纖維」、「蛋白質」、「複合碳水」、「精緻糖」等標籤，建立當前餐點的進食順序。
- **欄位需求**: 
  - 食物類別 (Type): 必填。
  - 進食順序 (Index): 自動生成。
- **狀態**: 🟢 已設計 / ⚪ 待實作

### 1.2 即時分數計算
- **行為描述**: 根據 `ARCHITECTURE.md` 定義的演算法，在使用者調整順序時即時更新總分。
- **業務邏輯**: 
  - 偵測「纖維」是否出現在序列首位。
  - 檢查「碳水」之前是否有足夠的「緩衝物」。
- **狀態**: 🟢 已設計 / ⚪ 待實作

### 1.3 評分視覺化回饋
- **行為描述**: 根據分數區間顯示不同的視覺提示。
  - **80-100**: 綠色（優良，血糖平穩）。
  - **60-79**: 黃色（尚可，有改善空間）。
  - **< 60**: 紅色（警示，建議調整順序）。
- **狀態**: ⚪ 待實作

## 2. 歷史紀錄 (Meal History) - *未來規劃*
- **行為描述**: 儲存每次進食的分數與順序，以日曆或列表形式展現。
- **狀態**: ⚪ 待規劃

## 3. 衛教建議 (Dietary Tips) - *未來規劃*
- **行為描述**: 針對當前評分結果，提供具體的改善建議（例如：「下次嘗試先吃完蔬菜再吃白飯」）。
- **狀態**: ⚪ 待規劃
